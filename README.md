# Abhay Bhardwaj — Business Portfolio

Responsive static portfolio website built with HTML and CSS.

## Files
- `index.html` — website
- `resume.pdf` — résumé linked from the homepage
- `certificates/` — place the original certificate PDFs in this folder using the exact filenames listed in `certificates/README.txt`

The certificate cards include a **View PDF** link to the matching local file and a **Check Online** link to the supplied credential URL.

Before publishing, replace `YOUR_PHONE_NUMBER` in the Contact section's `tel:` link with your phone number and update its visible label if you want the number displayed.

Open `index.html` in a browser to preview the site. For GitHub Pages, upload the contents of this folder to the repository.
